    Configurar Google OAuth & Client ID

    Para activar la sincronización directa sin salir de esta web, ingresa tu Client ID de Google Cloud Console.

    ¿Cómo obtener tu Client ID en 3 pasos?
    1. Entra a Google Cloud Console y crea un proyecto.
    2. Activa las APIs de Google Calendar API y Google Tasks API.
    3. Ve a Credenciales > Crear credenciales > ID de cliente OAuth (Aplicación web) y agrega la URL de tu repositorio de GitHub Pages como origen autorizado.
